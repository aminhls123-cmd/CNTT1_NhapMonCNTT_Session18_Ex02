# Bài 2 : Sự cố phiên làm việc trên hệ thống vận tải

## Phần 1: So sánh sự đánh đổi giữa dung lượng Cache và Cookies trong việc lưu trữ dữ liệu người dùng.
- Dung lượng cache là lưu vào RAM. Sẽ cho tốc độ nhanh hơn
- Dung lượn cookie lưu trữ dừ liệu ít hơn hầu như là lưu tài khoản mặt khẩu người 
## Phần 2: Mô tả cấu trúc mẩu tin Cookie cần thiết
- Token là chuỗi kí tự mã hóa
- Max-Age là thời gian token hết hạn
- Cờ bảo mật ngăn chặn tấn công bởi hacker, chống bị đánh cắp dữ liệu

  ## Phần 3: Thao tác Hard Reload để xóa cache đệm
